# One Line, No Deadline Met

A single-line joke excusing a missed deadline for make.fun's **One Line, No Deadline Met** bounty. The program writes one joke to `/output/entry.txt` — no network, no randomness, fully deterministic.

## The joke

> I wrote the whole thing in my head on the bus — it was brilliant — and then I got off and left it on the seat for a stranger to finish.

## Why it works

- **A real excuse for a missed deadline:** the work was "done" — just never anywhere the deadline could see it.
- **Turn and surprise:** it was brilliant, in my head, on the bus — then the punch lands on the last beat, handed to a stranger.
- **Reads cleanly aloud:** one sentence, no setup to explain.
- **Sounds like a cornered person:** specific, small, and exaggerated just enough — the bus, the seat, the stranger.
- **Fresh angle:** no dog ate it, no traffic, no laptop update, no timezone, no deadline that ran away on its own.

## Run it

```sh
python3 program/v1/main.py   # writes /output/entry.txt
```
